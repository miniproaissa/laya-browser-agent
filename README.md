## 🎯 What Is This?

laya-browser-agent is a free, open-source program that lets your computer use a web browser on its own. It's like having a personal assistant that can click buttons, fill forms, navigate websites, and complete tasks for you — all without sending your data to the cloud.

This is a local alternative to paid services. You own everything. No accounts, no subscriptions, no internet required after setup.

## 🐛 Troubleshooting

**Problem:** Program won't start  
**Fix:** Make sure you have the latest version. Try right-clicking the file and selecting "Run as administrator."

**Problem:** Browser opens but nothing happens  
**Fix:** Wait a few seconds — the agent is thinking. Give it time to process the task.

**Problem:** Task fails halfway  
**Fix:** Simplify your instruction. Break it into smaller steps.

**Problem:** It asks for permission  
**Fix:** Click "Allow" — this lets the program control the browser window.
